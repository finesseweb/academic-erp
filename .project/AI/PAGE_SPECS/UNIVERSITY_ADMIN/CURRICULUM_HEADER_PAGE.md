# Curriculum Header

## Status
Implementation: NOT_STARTED. Review: NOT_APPLICABLE.

University-owned versioned curriculum header for an active Program Template and Academic Session. It records a unique University code, name, version, effective dates, draft/active/retired lifecycle and description. Terms, slots and course mapping belong to the subsequent Curriculum Manage Structure milestone. Permissions: `curriculum.view/create/update/disable`; audit events: `CURRICULUM_*`.
