# University Administration Page Delivery Order

## Meaning
`SUPER_ADMIN` is the highest University-level role. The application workspace is University Administration because the University is the domain root.

2. Forgot Password

4. Change Password
5. Profile

## Phase UA-05 — University & Affiliated Colleges
1. `UNIVERSITY_PROFILE_PAGE.md`
2. `AFFILIATED_COLLEGES_LIST_PAGE.md`
3. `AFFILIATED_COLLEGE_CREATE_PAGE.md`

Each Affiliated College may contain Administration, Campus, Faculties/Schools, Departments, Programs, Batches, Semesters/Terms, Courses/Subjects, Faculty/Employees, Students, Parents/Guardians and College Fee Management.

College Fee Management includes College Fee Structure, Installment Plans, Student Fee Assignment, Demand/Invoice, Collection/Receipt, Dues/Late Fees, Discounts/Waivers, Refunds/Reversals and College Finance Reports.
