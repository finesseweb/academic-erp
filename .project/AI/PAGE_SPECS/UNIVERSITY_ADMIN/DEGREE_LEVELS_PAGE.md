# Degree Levels Page

## Status
- Implementation: IMPLEMENTED
- Review: PENDING_REVIEW
- Implemented: 2026-08-21

## Contract
University-owned ordered degree classifications (for example Undergraduate, Postgraduate and Doctoral). Code is unique per University. Records are retained and activated/deactivated rather than deleted. “Degree Levels” is the canonical hierarchy term; it supersedes the older generic “Degree Types” label for this milestone.

## UX
Responsive theme-token list/cards, create/edit dialogs, inline validation, processing lock/spinner, ordered display, lifecycle badges and empty state. Permissions: `degree_level.view/create/update/disable`.
