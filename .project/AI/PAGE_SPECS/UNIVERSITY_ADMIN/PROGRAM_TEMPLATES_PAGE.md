# Program Templates
## Status
Implementation: IMPLEMENTED. Review: PENDING_REVIEW. Implemented 2026-08-21.

Reusable University program blueprints for later College offerings. Each requires an active same-University Degree, may reference an active discipline/specialization, and defines term structure and duration. Unique University code, order, status and description are supported. Permissions `program_template.view/create/update/disable`; audit `PROGRAM_TEMPLATE_*`; REST-only Inertia and shared academic-master UX.
