# Program Templates
## Status
Implementation: IMPLEMENTED. Review: PENDING_REVIEW. Implemented 2026-08-21.

Reusable University program blueprints for later College offerings. Each requires an active same-University Degree and top-level Discipline; it may additionally reference one active Specialization belonging to that Discipline. The Specialization selector is optional and filtered by the selected Discipline. Unique University code, order, status and description are supported. Permissions `program_template.view/create/update/disable`; audit `PROGRAM_TEMPLATE_*`; REST-only Inertia and shared academic-master UX.
