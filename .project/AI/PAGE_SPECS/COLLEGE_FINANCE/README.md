# College Finance Page Hierarchy

This folder implements the College Fee Management branch of the canonical University hierarchy.

College Fee Management
- College Finance Dashboard
- College Fee Structure
- Installment Plans
- Student Fee Assignment
- Demand / Invoice
- Collection / Receipt
- Dues / Late Fees
- Discounts / Waivers
- Refunds / Reversals
- Installment Rescheduling
- College Finance Reports

All pages must follow:
- `.project/AI/DOMAIN/UNIVERSITY_HIERARCHY.md`
- `.project/AI/DOMAIN/FEE_GOVERNANCE_AND_INSTALLMENTS.md`
- `.project/AI/SECURITY/PERMISSION_CATALOG.md`
- `.project/AI/DATABASE_RULES.md`

University-fixed fee amounts are never editable by College users.
