# ADR 058 — Applicant Header Steps, Right Progress/Help, and No Term/Credit UI

Date: 2026-08-31
Status: Accepted

Public admission application presentation rules:

- Header contains the arrow/chevron step navigator.
- Future steps remain locked until the current step passes required validation.
- Completed/unlocked steps remain editable until final submission.
- Progress donut is shown in the fixed right rail, below Applicant Profile.
- A College-editable “Need Help?” block appears below Progress.
- College controls Help text through Admission Form Setup > Applicant Registration settings.
- Applicant academic choice UI does not expose Semester/Term headings or credit values.
- Choice categories are consolidated across hidden curriculum terms.
- Where a category forms a fixed source-discipline package across terms, applicant chooses only the package (e.g. History); underlying term/course mappings are submitted internally.
- Where genuine course-level choice exists, individual courses remain selectable, while term placement and credit structure stay internal.
