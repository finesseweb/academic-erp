# fee_demands / fee_demand_items

`fee_demands` is the payable admission-level financial snapshot generated from effective Fee Setup. It stores admission/offering/session/curriculum context, billing period number, demand number/currency, total, mandatory total, enrollment-clearance total, paid/adjusted/outstanding placeholders, lifecycle and generation/cancellation audit.

ADR 118 adds demand provenance/context fields:
- `demand_context` — `ADMISSION_INITIAL`, `ACADEMIC`, `EXAMINATION`, `OTHER` (legacy rows may be null),
- `billing_basis_group` — `TERM`, `ACADEMIC_YEAR`, `ONE_TIME`, or `MIXED` for the admission-stage snapshot,
- `billing_period_label` — immutable human-readable label such as `Admission Initial`, `Semester 1`, `Trimester 1`, or `Academic Year 1`,
- `bulk_run_key` — groups demands generated by one Program Offering bulk action.

`fee_demand_items` snapshots each applicable University/College Fee Structure Item including exact source period, Fee Head, Fee Structure purpose/collection basis, amount and the period-effective `is_mandatory`, `is_enrollment_clearance_required`, `installment_allowed`, and Fee Head `is_refundable` flags. Refundability is snapshotted at demand generation and does not silently change when the Fee Head is edited later.

A non-cancelled demand cannot re-charge the same `fee_structure_item_id` for the same admission and exact `source_period_no`. This protects against an Academic first-period bulk run duplicating a source item that was already included in the Admission Initial demand as an Enrollment-Clearance charge.

Existing demand snapshots are immutable with respect to later Fee Foundation changes.

## Academic Period Link - 2026-09-12

The Demand does not directly reference `academic_calendar_term_periods`.
Calendar-period validation occurs in Fee Setup. Generation then snapshots
`billing_period_no`, `billing_period_label`, `billing_basis_group`, Curriculum
context, and each item's `source_period_no` and `due_date`. Later Calendar or Fee
Setup changes must not reinterpret an existing Demand.
