# program_templates
University-owned blueprint with RESTRICT FKs to University, required Degree, required top-level Discipline and optional Specialization. The optional Specialization must belong to the selected Discipline; existing historical null Discipline values remain supported by the physical schema migration, while all new and updated templates require a Discipline. Contains unique University code, name, `SEMESTER|YEAR|TRIMESTER` structure, duration terms, description, display order, status and timestamps. Non-unique `program_tpl_scope_order_idx (university_id, degree_id, status, display_order)` supports governed lists.
