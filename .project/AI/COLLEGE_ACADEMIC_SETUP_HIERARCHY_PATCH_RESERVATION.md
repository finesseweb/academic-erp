# College Academic Setup Hierarchy — Reservation Milestone

1. Program Offering
2. Intake / Seat Capacity
   - Program capacity OR
   - Discipline capacity
     - optional Specialization child capacity
     - derived General Discipline remainder
3. Reservation / Seat Distribution
   - effective admission seat buckets
   - Vertical quota partitions seats
   - Horizontal quota overlays seats
4. Admission Setup / Admission
5. Student Lifecycle
6. Batches / Sections and later academic delivery modules

Later modules must reference preceding operational records rather than bypassing them.
